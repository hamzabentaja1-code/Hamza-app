# HamZa v0.8.0

مشروع Android مستقل باسم HamZa والحزمة `com.hamza.app`.

## الموجود حالياً
- المنتجات مع ثمن الشراء وثمن البيع وهامش ربح الوحدة والربح المحتمل للمخزون، وإضافة/تغيير/حذف صورة المنتج ومعاينة مكبرة والبحث والتعديل، مع حفظ محلي عبر AsyncStorage؛ الزبناء والموردون أيضاً.
- نقطة بيع POS: بحث بالاسم، سلة متعددة المنتجات، تعديل الكمية، تخفيض عام، اختيار الزبون وطريقة الأداء، التحقق من المخزون، تسجيل البيع وتحديث المخزون وإصدار وصل PDF.
- المبيعات والمشتريات وتحديث كمية المخزون.
- المصاريف، عروض الأسعار، الأداءات والتقارير الأولية.
- إنشاء PDF ومشاركته لبعض وثائق البيع والمصاريف والأداءات.
- تصدير نسخة احتياطية JSON واسترجاعها يدوياً عبر النسخ واللصق، مع التحقق من بنية النسخة قبل الاسترجاع.
- الواجهة بالعربية والفرنسية مع اتجاه RTL/LTR، وحفظ البيانات محلياً. أضيفت إدارة المشاريع وربطها بالزبناء، وتتبع أداءات الموردين، وحساب الربح الإجمالي اعتماداً على تكلفة المنتج وقت البيع.

## البناء والفحص
GitHub Actions يشغّل اختبارات المستندات وفحص TypeScript عند تحديث main، ويبني APK من نوع Release مع اختبار Android ومراجعة MobSF عند تشغيل البناء يدوياً.
ملف APK الناتج موقّع بمفتاح مؤقت ينشأ لكل تشغيل CI بغرض التجربة الداخلية فقط. هذا التوقيع ليس مفتاح إصدار دائم؛ لا يمكن ضمان التحديث فوق نسخة سابقة موقعة بمفتاح آخر. قبل النشر أو التوزيع المستمر يجب إعداد مفتاح توقيع دائم محفوظ خارج المستودع في GitHub Actions Secrets.
إعداد Android يحدد الحد الأدنى API 29 ويمنع cleartext traffic، ويحذف صلاحيات التخزين والـ overlay غير المطلوبة.
نجاح البناء أو MobSF لا يثبت اكتمال الوظائف ولا يغني عن اختبار التطبيق على جهاز Android فعلي ومراجعة تقرير الفحص.

## وحدات منطق الأعمال
تمت إضافة واجهة المشاريع وتتبع دفعات الموردين وتكلفة البيع في هذه المرحلة. ما زالت مراجعة كل مسارات التطبيق على جهاز فعلي مطلوبة قبل اعتباره إصداراً تجارياً.

## حدود النسخة
هذا مشروع مستقل لإعادة تنفيذ الوظائف المعروفة، وليس نسخة مطابقة من YanCommerce، ولا يتصل بخادمه أو حساباته. البيانات محلية على الجهاز. المشروع ما زال نموذجاً أولياً، ويلزم استكمال الواجهات والاختبارات قبل الاستعمال التجاري.

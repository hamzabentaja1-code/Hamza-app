# HamZa v0.7

مشروع أولي مستقل لتسيير المبيعات والمخزون. الاسم والحزمة: `HamZa` / `com.hamza.app`.

## الموجود حالياً
- المنتجات، الزبناء والموردون مع حفظ محلي عبر AsyncStorage.
- المبيعات والمشتريات وتحديث كمية المخزون.
- المصاريف، عروض الأسعار، الأداءات والتقارير الأولية.
- إنشاء PDF ومشاركته لعروض الأسعار والفواتير وسندات الخروج، وإيصالات المشتريات والمصاريف والأداءات.
- واجهة عربية أولية مع تبديل علامة اللغة AR/FR (الترجمة الفرنسية الكاملة غير مكتملة).

## تشغيل المشروع
يتطلب Node.js و npm واتصالاً بالإنترنت لتنزيل الحزم:

```bash
npm install
npx expo start
```

لبناء APK محلياً يمكن إعداد EAS Build أو Android SDK/Gradle. لم يتم بناء APK أو اختباره على هاتف فعلي في هذه النسخة.

## وحدات منطق الأعمال المضافة
- دورة وثائق البيع وحالاتها وربط سند التسليم بالفاتورة.
- بيانات الزبناء والموردين المغربية: ICE وRC وIF وشروط الأداء والرصيد.
- سجل حركات المخزون وتحويل السلع بين المخازن وتقييم المخزون.
- حسابات نقطة البيع POS والبحث بالباركود والتخفيضات والتحقق من الأداء.
- دورة المشتريات وأداء الموردين.

بعض هذه الوحدات موجودة حالياً كمنطق برمجي مستقل ولم تُربط كلها بعد بواجهات التطبيق.

## حدود النسخة
هذا مشروع مستقل لإعادة تنفيذ الوظائف المعروفة، وليس نسخة مطابقة من YanCommerce، ولا يتصل بخادمه أو حساباته. البيانات محلية على الجهاز. يلزم اختبار شامل قبل استعماله تجارياً.
